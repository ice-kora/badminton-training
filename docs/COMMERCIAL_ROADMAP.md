## Q1 路径（按依赖排序）

1. **分享资产（本轮）** — Moments 可晒图 → 拉新与社交证明；水印保留体验版身份；去水印作为高 WTP 信号（尚未变现）。
2. **存储 TTL（本轮）** — 原片 7 天清理，降低对象存储与合规成本；分析资产长留，支撑复测对比与成长页。
3. **端侧姿态（后续）** — 见 `CLIENT_SIDE_POSE_SPIKE.md`：可行性 spike，**非**本轮交付。目标是 JSON-only 上传，逼近 Zero-Ops。
4. **教练 B2B SaaS（后续）** — 多学员看板、作业下发、俱乐部账号；**本轮不做**。
5. **俱乐部兑换码（后续）** — 线下课包 / 体验卡兑换高级导出或更多复测位；**本轮不做**。

## 变现与风险（诚实）

- **iOS / 微信虚拟支付**：小程序内数字商品易触达苹果 IAP 与微信虚拟支付规则；「去水印高清导出」若收费，需单独评估类目、资质与审核话术，**禁止**本仓库先接假支付。
- **High WTP 候选**：去水印装逼卡、长留原片、教练批注位、俱乐部兑换码；需用复测率（见 `PRODUCT_METRICS.md`）验证后再接真支付。
- **Zero-Ops**：仅在端侧姿态稳定 + 服务端只收 JSON / 轻量评分时才接近；当前仍依赖服务端抽关键点 worker。

## 明确不做（本轮）

- 真实微信支付 / IAP / 订阅扣费
- 教练 B2B 多租户
- 完整端上 MediaPipe / VisionKit 量产
- 实时摄像头纠错、假分、伪 AI

## 运维提示

- 原片清理：`make purge-videos` 或 `python -m app.worker purge-videos --once`（详见 `RUN.md`）
- 环境变量：`VIDEO_TTL_DAYS`（默认 7）
